FINTECH & PAYMENTS / PROJECT

Moneris Checkout Integration Lab.

A QA-focused toolkit for building, inspecting, and running Moneris Checkout flows. The project combines a preload JSON builder, a customer-facing hosted checkout demo, and a serverless backend that keeps Moneris credentials out of the browser.

ARCHITECTURE

Public UI. Private credentials.

Browser → Cloudflare Worker → Moneris QA → Checkout ticket → Hosted Checkout

Store ID, API token, and Checkout ID stay in Cloudflare secrets. The public site sends only the transaction data needed for the demo and receives the temporary checkout ticket.
