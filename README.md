# WrittenByD Portfolio

Technical portfolio for John-Douglas McGregor / WrittenByD.

## Purpose

This site turns Coursera learning and independent technical work into documented, inspectable projects.

Each project should eventually capture:

- Problem
- Goal
- What was built
- Architecture / flow
- Technologies used
- Key decisions
- Challenges and debugging
- Results
- Lessons learned
- GitHub repository
- Live demo, when applicable

## Current stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub

The architecture is intentionally lightweight so projects can be added quickly. It can later migrate to React/Next.js if the portfolio grows beyond what a static site handles comfortably.

## Project categories

- Fintech & Payments
- Software Development
- Cloud & DevOps
- Data & Analytics
- Networking & Security
- Automation & AI

## Adding a project

Add a new object to the `projects` array in `script.js`. The project grid, filters, search, and case-study modal are generated from that data automatically.
